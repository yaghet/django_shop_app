# Онлайн Магазин Megano
Онлайн магазин, позволяющий покупать и заказывать товары.

---

## Установка проекта

### Данный проект использует установку зависимостей с помощью пакетного менеджера - `UV`.

1. **Инструкция по установке `UV` и создания виртуальной среды с установкой зависимостей**:
   - Для Windows:
     ```
     powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
     ```
   - Для macOS и Linux:
     ```
     curl -LsSf https://astral.sh/uv/install.sh | sh
     ```
2. **Создание виртуальной среды**:
   - Выполните команду в корне проекта:
     ```
     uv init
     ```
3. **Установка зависимостей**:
   - Выполните команду в корне проекта:
     ```
     uv sync
     ```

---

## Использование проекта

1. **Перейдите в папку Online-shop, используя терминал**
   - Выполните команду:
     ```
     cd online-shop
     ```
2. **Миграции базы данных**:
   - Выполните команду в директории online-shop:
     ```
     python manage.py migrate
     ```
3. **Загрузка тестовых данных**
   - Выполните команду в директории online-shop (Не обязательно!)
     ```
     python manage.py loaddata --exclude=contenttypes fixtures/fixtures.json
     ```
4. **Запуск сервера**:
   - Выполните команду в директории online-shop:
     ```
     python manage.py runserver
     ```
5. **Открытие в браузере**:
   - Перейдите по адресу: `http://localhost:8000/`

## Возможности
- **Просмотр товаров**: Просмотр списка доступных товаров.
- **Оформление заказов**: Возможность оформить заказ на выбранные товары.
- **Управление заказами**: Возможность просматривать и управлять заказами.
